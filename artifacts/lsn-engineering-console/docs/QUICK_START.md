# Quick Start

1. Launch **LSN Engineering Console**. Replit always starts in **Simulation Mode**.
2. Select **Discover LSN Devices** and choose `LSN-SIM-001` (`192.168.1.50`).
3. Connect and run **Basic Communication Tests**.
4. Use **Control** to compare requested, reported, and hardware-control states.
5. Open **Protocol Inspector** to inspect decoded and raw simulated transactions.
6. Use **Firmware** to rehearse update, reboot, rediscovery, validation, and rollback.

Hardware Mode remains non-transmitting until real CIP mappings and the maintenance endpoint are implemented and physically validated.
